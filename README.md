# Супербудильник

Будильник для Android, который нельзя выключить, пока не решишь пример вроде `22 + 34`.

## Возможности

- Несколько будильников, у каждого время, дни недели, название и мелодия
- Без выбранных дней будильник срабатывает один раз
- Громкость нарастает плавно, есть вибрация
- Выключить или отложить на 5 минут можно только после правильного ответа
- Кнопки «Назад» и громкости не работают; если свернуть, экран будильника вернётся
  (нужно разрешение «Поверх других окон»)
- После перезагрузки телефона будильники восстанавливаются

## Установка

1. Откройте на телефоне раздел **Releases** этого репозитория.
2. Скачайте `super-alarm.apk` из последней сборки и установите
   (телефон попросит разрешить установку из этого источника).
3. Откройте приложение и нажмите все кнопки разрешений вверху экрана.

## Сборка

APK собирается автоматически через GitHub Actions при каждом push в `main`.
Требования: Android 12+.

Файл `app/debug.keystore` — отладочный ключ подписи. Он лежит в репозитории, чтобы новые сборки
ставились поверх старых без потери будильников.
